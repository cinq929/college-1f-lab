# 设计学院一层：路线、触觉引导与视觉码实验

日期：2026-11-09。依据为用户提供的双层建筑图，下半张明确标“一层平面图”。上半张为三层，本轮不建模。所有方案是现场核对前的实验草案。

## 2. 路线与算法

环线：南侧起点0 → 起步检查1 → 西南转角2 → 西侧横道3 → 咖啡厅外4 → 西北转角5 → 油泥工坊门外6 → 丝网印工坊门外7 → 东北转角8 → 阅览室外9 → 东侧横道10 → 东南转角11 → 起点0。只在门外停靠，不进入房间。当前图纸估算长198.7m。

已实现：在人工标注的通行区上，以3px栅格做8邻域A*，每段检测净空和墙体，再用视线检查简化；每一步模拟移动检查障碍。路径长度是按采样图估算，不宣称全局连续最优，更没有优化参观站点的排列顺序。

这轮刻意使用“同层外围保守路线”，而不是用最短距离穿越中央台体。下一轮如果现场确认坡道无障碍条件，再单独增加边，并记录坡度／门宽／高差约束。

## 3. 触觉引导与贴码是两层设施

- 绿色线：沿确认后的走廊布置连续导向的候选中心线。它还不是实际铺装线，更不是自动确定了盲道条宽和距墙尺寸。
- 橙色框：起终点、功能停靠和约35°以上转向的提示位置候选。当前共16处，包含A*为避柱产生的局部转向；现场可合并成清晰决策区，不能照搬16块统一点状铺装。
- 红叉：必须核查的楼梯／高差区域。不将其作为参观目标，不用算法朝那里指引。提示铺装的类型、距危险边缘距离和防护应由现场无障碍专业审核确定。
- 彩色 ID 点：稀疏码候选，优先起点、交叉口、转弯前和工坊门外停靠区。不要贴在凸起盲道、门扇扫过区或人流集中踏踩区；先在同侧平整区域选实际点，再测量并更新坐标／朝向。
- 码不能代替手杖可触知的连续引导。低视力／全盲用户如何把相机对准地码，本轮没有解决，需要结合可触知定位点和辅助对准交互实测。

触觉指南的作用是明确引导、警示和语义一致性；本工具不自动判定符合中国当地规范。中国项目的具体铺装设计应再依据适用无障碍规范及学校审批。

## 4. 关键点稀疏码与连续覆盖补码

输入“识别斜距上限2m、相机高度1.2m”，可用水平半径最多 sqrt(2²−1.2²)=1.6m。2m是已有肉眼观察的可扫距离条件，不是已证明的测距精度或成功率。

方案A：只保留12个候选ID。当前72/267个路线采样点满足距离和图上视线条件，约27.0%。中间位置没有新观测，页面不能声称在连续追踪。

方案B：沿路线生成约1m间隔的候选码点，用单位成本的贪心集合覆盖：每次增加覆盖最多未覆盖采样点的点，直到没有收益或用完预算。先保留关键ID点，再补P候选。当前需要补61点，267/267采样点满足条件；不是整个真实空间均可识别的证明。P点只是建议，不自动登记为ID或触发现场语音。

这是离散覆盖启发式，不是最少码数量的精确最优解。采样间隔、候选间隔和预算会影响结果。地图只检测同层平面视线，不模拟相机视场、俯仰、透视像素大小、反光、遮挡或姿态误差。即使100%也只能说满足必要的图上条件。

连续覆盖需要很多码本身就是实验结论；若不希望密集铺码，应研究视觉惯性／PDR等连续定位，再用稀疏码纠偏，而不是把“看不见码时沿上次位置走”包装成实时定位。本轮没有加入或伪造这种跟踪。

## 5. 先执行的12m短段实验

1. 网站点击“先试12m短段：0→1”。实地确认南侧这段确是同层、无台阶、足够宽且允许实验；不符则移动起终点或先换一段直廊。
2. 用卷尺量图上约12m的起终点间距，以及另一条垂直参考段。记录图纸误差；在页面人工应用现场比例。记录手机、镜头、分辨率和相机标定ID，实量黑色码框，不含白边。
3. A组仅贴起终点两个80mm码；B组按页面补码建议布置，并现场测量坐标与安装转角。先用同一部手机和同一高度1.2m比较，保持路线与光照一致。
4. 真值检查点每1m一处。每处分别朝向码、前进方向、转身约30°采集，每种条件重复10次。记录成功次数、ID、角点像素、斜距、重投影RMS、解算坐标、卷尺真值、时间和丢码区间。真实相机扫描仍沿用已有标定＋PnP链路。
5. 计算检测成功率、定位水平误差中位数/P95、最长丢码距离；覆盖率必须以实测成功来统计，不使用页面几何覆盖率充当结果。按每次测量报告，不伪造尚未采集的数据。
6. 先由视力正常组员在陪同下核验路线、左右声道和停止逻辑。做参与者引导实验前须完成现场高差／障碍核查和学校要求的审批。不要用蒙眼自行走楼梯来验证本原型。
7. 通过后再扩展到单个转弯（ID1→2→3），最后才评估约199m外围环线。比较人工指定候选、贪心补码、以及实测遮挡条件下的差异。

建议记录CSV列：trial,condition,phone,calibrationId,frameWidth,frameHeight,markerId,markerSizeMm,cameraHeightM,gtX_m,gtY_m,estimatedX_m,estimatedY_m,slantM,rmsPx,detected,elapsedMs,note。
